## [Unreleased]

### Added
- Initial project structure setup
- Backend FastAPI application with modular architecture
- Frontend Electron + Vue desktop application
- ESP32 firmware for distributed hardware nodes
- Live2D avatar rendering engine
- Voice interaction system (ASR/TTS)
- Multi-layer memory system (episodic, semantic, working memory)
- MQTT-based IoT control integration
- Redis state management
- PostgreSQL with pgvector for vector storage
- Multi-platform LLM provider support (OpenAI, Anthropic, LiteLLM)
- WebSocket real-time communication
- JWT authentication and OAuth integration
- Plugin system with hot-reload support
