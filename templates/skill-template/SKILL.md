# 技能标题

> 技能 body 是注入给 LLM 的**行动指引**：写"AI 应该怎么做"，而不是产品介绍。
> 建议结构：首要动作 → 执行步骤 → 边界 → 记忆联动。

## 首要动作

最关键的一步放在最前面（例如：先把关键信息存为置顶记忆）。

## 执行步骤

1. 第一步：……
2. 第二步：……
3. 输出格式与长度约束（如：3-6 句话、不要 markdown 标题）。

## 边界

- 明确"不要做什么"（不评判、不越界、不模板化）。
- 涉及专业领域（医疗/法律/心理危机）时的转介原则。

## 记忆联动

- 本技能应记住什么（偏好、反馈、结果），供下次个性化。
- 应联动读取哪些已有记忆（画像、置顶事实、每日记录）。
