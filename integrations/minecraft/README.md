# 我的世界 (Minecraft) 具身伴侣接入指南

LuomiNest 支持将系统内的 **【主Agent】** 派驻进《我的世界》(Minecraft Java 版) 作为一名具身虚拟玩家（Embodied Companion Bot），与玩家并肩冒险、挖矿、建造、探索并实时对话交流。

---

## 🌟 核心特性与主 Agent 继承机制

1. **主 Agent 身份全量接管**：
   - 伴侣机器人的**玩家游戏昵称**直接继承自系统设置中的 **【主Agent名称】**（若留空默认使用 `主Agent`，也可在实例配置中自定义）。
   - 伴侣在游戏内公屏发送聊天信息时，完全遵循主 Agent 设定的人格提示词、语气和上下文记忆。
2. **多版本与原版客户端支持**：
   - 深度集成基于 Node.js Mineflayer 的具身网关（内置于 `backend/scripts/mc_bot/`）。
   - 支持 Minecraft 1.8 至 1.20.x、1.21.x（含 Protocol 776）全版本原生自适应协商协议。
   - 无论是官方原生客户端（Vanilla）、纯净启动器、还是 Fabric / Forge 模组端均可完美支持。
3. **具身遥测与智能交互**：
   - 伴侣实时向 LuomiNest 回传周围方块、血量、时间、附近玩家距离等具身遥测状态（Telemetry）。
   - 支持大模型自主调用游戏内工具：移动跟随、朝向观察、动作跳跃、放置/挖掘方块、背包管理等。

## 🚀 快速启动指南

### 1. 单人游戏（对局域网开放模式）—— 最简极速联机

如果你在自己的电脑上玩单人单机存档：

1. 打开 Minecraft 游戏并进入单人世界。
2. 按 `ESC` 键打开菜单，点击 **“对局域网开放” (Open to LAN)**。
   - 允许作弊：可根据个人喜好开启或关闭。
   - 游戏模式：生存 / 创造。
3. 点击 **“创造一个局域网世界”**。
4. 游戏左下角聊天框会弹出一行提示，例如：
   ```text
   本地游戏已在端口 56587 上开启
   ```
   **记住这个 5 位数端口号（例如 `56587`）**。
5. 打开 LuomiNest 桌面客户端：
   - 进入 **工作台 -> 平台对接** 页面。
   - 找到 **Minecraft** 实例卡片，点击 **设置**（齿轮图标）。
   - 在弹出的配置窗口中：
     - `game_port`: 填入刚才游戏内提示的 5 位端口号（例如 `56587`）。
     - `game_host`: 填 `127.0.0.1`。
     - `bot_name`: 留空即可（留空时将直接继承你在设置里配置的主 Agent 名字）。
     - `auto_spawn_bot`: 填 `true`（系统将自动拉起 Mineflayer 虚拟玩家入服）。
   - 点击 **保存配置**。
6. 点击该实例的 **启动** 开关。
7. 返回游戏画面，即可看到你的主 Agent 伴侣进入了游戏，并在公屏打招呼！在游戏内打字即可与它实时聊天。

---

### 2. 多人独立服务器（Paper / Fabric / Spigot / 原版服务端）

如果你开设有专门的 Minecraft 独立服务器：

1. 确保服务端 `server.properties` 中的 `online-mode` 配置为 `false`（离线验证模式，以便虚拟伴侣以非正版离线模式快捷登入）。
2. 在 LuomiNest Minecraft 实例配置中：
   - `game_host`: 填入服务器 IP（如 `127.0.0.1` 或局域网/公网 IP）。
   - `game_port`: 填入服务器端口（原版默认 `25565`）。
   - 保存并启动即可。

## ⚙️ 常见问题与排错 (FAQ)

- **Q: 提示连接拒绝 (ECONNREFUSED) 或超时？**
  - **A**: 单人游戏每次重新进入世界或重新点击“对局域网开放”时，端口号都会动态变化。请确认填写的 `game_port` 与游戏左下角显示的最新端口一致。
- **Q: Node.js 环境依赖？**
  - **A**: LuomiNest 的具身伴侣脚本运行在 Node.js 环境中，请确保本地已安装 Node.js (推荐 v18+ 或 v20+)。
- **Q: 名字显示为英文还是中文？**
  - **A**: Minecraft 原生离线协议对用户名字符有一定限制（建议 3-16 位字母、数字或下划线，部分启动器支持 UTF-8 字符）。若在原版服务端中文名被阻断，可在 `bot_name` 中指定纯字母英文代号（例如 `LumiAgent`），其对话与人设依旧 100% 保持主 Agent 人格！
