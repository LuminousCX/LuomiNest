# 个人微信接入脚手架 (GeweChat / iPad 协议网关)

本目录为 LuomiNest 的个人微信接入提供本地化运行脚手架。基于 GeweChat（iPad 协议网关），支持原生收发文字、表情、图片、语音，并通过 Webhook 实时回调入 LuomiNest。

---

## 🌟 核心特性与主 Agent 继承机制

- **主 Agent 人格接管**：微信伴侣端直接继承系统设置中设定的 **【主Agent】** 名字与人设性格。
- **全自动化扫码登录与会话维护**：支持通过 LuomiNest 桌面客户端直接提取登录二维码、扫码、授权绑定，并自动持久化 Token。
- **双向即时互动**：支持好友私聊与微信群聊 @ 伴侣唤醒互动。

---

## 🚀 快速启动指南

### 1. 启动 GeweChat 容器

```bash
cd integrations/wechat_gewe
docker compose up -d
```
启动成功后，API 服务运行在 `http://127.0.0.1:2531`。

### 2. 在 LuomiNest 平台对接中配置

1. 打开 LuomiNest 桌面客户端 -> **工作台** -> **平台对接**。
2. 找到 **个人微信 (GeweChat)** 实例，点击 **设置** 图标。
3. 填入以下配置：
   - `api_url`: `http://127.0.0.1:2531/v2/api`
   - `token`: 若首次使用可留空，启动时系统会自动请求设备 Token。
4. 点击启动。系统将获取 iPad 协议登录二维码并提示扫码。
5. 使用个人微信手机端扫码授权，登录成功后实例状态切换为绿色“运行中”。

## 🛡️ 微信防封与账号安全风控守则 (WeChat Anti-Ban Guide)

个人微信协议在风控体系中属于最高警戒级别，**请严格遵循以下安全守则**：

1. **绝对禁止新号上线**：
   - 使用的微信小号必须注册满 **6 个月以上**，最好有至少半年以上的生活日常使用、朋友圈记录和绑卡实名。
   - 绝不能注册一个新微信后立即登录 iPad 协议，否则 99% 会在 24 小时内触发设备异常冻结。
2. **IP 网络环境与设备白名单**：
   - 运行 GeweChat 的设备 IP 必须是当前微信常用的家庭宽带 IP，不要频繁更换代理节点或机房 IP。
   - 首次登录扫码时，手机端尽量连接同一 WiFi 网络。
3. **频率管控与行为模拟**：
   - 避免在群内高频无节制刷屏；LuomiNest 适配器自带自然停顿防刷限制。
   - 严禁用来进行批量群发营销、被动添加大量陌生好友、群发外部跳转链接。
   - 建议仅用于个人好友或亲友群专属陪伴互动。
4. **会话缓存持久化**：
   - 确保 `data/` 挂载目录有效，避免每次重启 Docker 导致重新登录被腾讯视作频繁换机。
